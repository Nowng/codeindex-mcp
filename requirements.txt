# Python dependencies for the upstream Code Index MCP backend (CodeIndex/).
# Installed by scripts/setup.cjs (postinstall, step [c}) via `pip install -r`
# after the venv is created. Kept as a plain text file (not a bundled ./wheels/
# directory) so the plugin stays small enough for LM Studio Hub upload.
#
# Union of the upstream's own dependency sources:
#   CodeIndex/pyproject.toml      -> mcp, watchdog, tree-sitter*, pathspec, msgpack
#   CodeIndex/requirements.txt    -> + protobuf, libclang
#   CodeIndex/fastmcp.json        -> subset of the above
#
# NOTE: unlike the old ./wheels/ bundle, installing from PyPI needs network at
# install time, and `libclang`/`protobuf`/`tree-sitter*` need a prebuilt wheel
# for the host's platform+Python (or a C compiler to build from source).
